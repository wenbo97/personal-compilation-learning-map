# Generate Teaching Materials on Request

Applies to teaching deliverables and learning records.

- Teach primarily through conversation, using short code, single-step commands, and necessary artifact excerpts.
- Generate HTML lessons, experiment scripts, or learning records only when the learner explicitly requests them.
- Follow root `AGENTS.md` for organization, records, and the English-only requirement when writing materials.

# Implementation Boundaries and Evidence

Applies to mechanism explanations, experiment interpretation, and comparison conclusions.

- Distinguish **language specifications, concrete implementations, and tool versions**. Discuss Python separately from CPython, JavaScript from V8 / Node.js, and C# from .NET. Observe TypeScript type checking and code transformation separately from JavaScript execution.
- Support conclusions with version-matched official documentation, compiler or runtime source, and experiments.
- Separate actual observations, mechanism explanations, and hypotheses awaiting verification. State verification status when only documentation is available or the example has not run.
- State implementation, version, and relevant configuration limits for conclusions based on local observations. Follow root `AGENTS.md` for environment records.

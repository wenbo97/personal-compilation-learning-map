# Current Python Learning Entry Point

Applies to the starting point of the current introductory learning sequence.

- Begin with the introductory questions in [compilation-foundations.rules.md](compilation-foundations.rules.md).
- After establishing that framework, use: **What observable artifacts exist between a Python source string and its execution?**
- Confirm the actual interpreter, version, and path. Before introducing AST inspection, establish the prerequisite context and purpose according to [stepwise-guidance.rules.md](stepwise-guidance.rules.md). Apply its understanding checkpoints when moving from ASTs to code objects, bytecode, and corresponding mechanisms in other languages.

# Learner Background and Language Track

Applies to learning plans, topic selection, and explanation depth.

- Use **Python as the main track, JavaScript / TypeScript for comparison, and C# / Java as familiar reference points**. Introduce Go, Rust, C, and C++ as questions deepen.
- The learner recently used Python + Bash, commonly uses C#, PowerShell, and CMD, and has experience with Java, C#, and JavaScript. Connect explanations to this background.
- Start ASTs, disassembly, and debuggers with reading methods: show how to recognize key structures before exploring internals.
- Default to Chinese in conversation while retaining useful English terms, symbols, and tool names. For all project file content, follow the English-only requirement in root `AGENTS.md`.

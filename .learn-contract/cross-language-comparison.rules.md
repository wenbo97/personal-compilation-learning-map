# Compare Languages Through Shared Questions

Applies to topic selection, syntax explanations, and cross-language comparisons.

- Observe real artifacts through reproducible small experiments, then compare compilation and runtime mechanisms.
- Compare the same question across languages, such as what is produced before execution, where type checking occurs, or how function calls work.
- Connect syntax to compiled artifacts, type systems, memory models, or runtime behavior.
- Keep questions, inputs, and execution conditions comparable. Explain the relationships between corresponding mechanisms and artifacts, selecting the stages that actually apply to the question.
